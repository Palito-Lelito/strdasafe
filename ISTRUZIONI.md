# Aggiornamento StradaSafe 0.7

Sostituisci nel repository GitHub questi tre file:

1. `app/build.gradle.kts`
2. `app/src/main/AndroidManifest.xml`
3. `app/src/main/java/it/stradasafe/liguria/MainActivity.kt`

Dopo l'ultimo commit, apri Actions, attendi la compilazione, scarica l'artifact `StradaSafe-Liguria-APK` e installa `app-debug.apk`.

Funzioni 0.7: navigazione attiva, istruzioni italiane, sintesi vocale, avanzamento delle manovre, ricalcolo quando ci si allontana oltre 80 metri, camera 3D in inseguimento, velocità GPS e comando audio.

Nota: ricerca, mappa e routing richiedono ancora Internet. Questa è un'alpha di collaudo, non usare come unico ausilio alla guida.
